🥤 Sistema de Gestión de Tienda de Bebidas
Este es un sistema de gestión de tienda de bebidas desarrollado en Python con interfaz gráfica usando Tkinter y base de datos en MySQL. El proyecto fue creado con el objetivo de aprender desarrollo de aplicaciones de escritorio, lógica de negocios, manipulación de bases de datos y gestión de inventario.

🚀 Características principales
🛒 Registrar compras y ventas de bebidas

📦 Controlar el stock en tiempo real

👤 Gestión de clientes y productos

📊 Generar reportes básicos

🧭 Navegación fluida entre secciones desde una sola ventana

🔁 Botón de volver para mejorar la experiencia del usuario

🛠️ Tecnologías utilizadas
Python 3

Tkinter (interfaz gráfica)

MySQL (gestión de base de datos)

mysql-connector-python (conector para Python)
